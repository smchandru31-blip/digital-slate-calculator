Key decisions + why:
- Modular Pure C++: Created `firmware/src/CalcEngine.hpp` and `firmware/src/CalcEngine.cpp` without any hardware or Arduino framework dependencies. It builds identically on PC (`host/`) and ESP32 (`firmware/`).
- Recursive Descent Architecture: Real tokenizer and grammar parser (`parseAddSub` -> `parseMulDiv` -> `parseUnary` -> `parsePower` -> `parsePostfix` -> `parsePrimary`). Guarantees correct left-associativity for division and subtraction ($24/6*2=8$, $20-5-3=12$) and right-associativity for exponentiation ($2^{3^2}=512$).
- Unary Minus Hierarchy: Configured unary minus below power so that $-2^2 = -(2^2) = -4$ adheres to standard mathematical convention, while allowing bracketed powers $(-2)^2 = 4$ and negative exponents $2^{-2} = 0.25$.
- Unicode Math Operator Support: Tokenizer transparently supports standard ASCII (`+`, `-`, `*`, `/`, `x`) as well as multi-byte UTF-8 symbols generated by handwriting OCR engines (`−` U+2212, `×` U+00D7, `÷` U+00F7, `√` U+221A).
- Experimental Operators: Marked powers (`^`), square roots (`√`), and percent (`%`) as experimental extensions until end-to-end touchscreen testing is completed.
